# Проект "Поиск вакансий"

Этот проект — консольное приложение для поиска и хранения вакансий с сайта hh.ru через их API.

## Основные возможности
- Поиск вакансий по ключевым словам
- Сохранение вакансий в локальный JSON-файл
- Просмотр топ N вакансий по зарплате
- Фильтрация сохранённых вакансий по ключевым словам

## Структура проекта
- `src/` — исходный код
- `tests/` — тесты с использованием pytest
- `README.md` — документация
